# 折光 · 项目与任务协作工作台

面向个人和小团队的项目管理应用，把项目、任务、讨论和团队管理放在同一个工作空间里。包含前端界面、管理后台与可持久化的后端服务。

界面采用紫色玻璃质感，配有流动光带、折射叠层、卡片渐入、弹窗过渡和任务拖拽动画；支持窄屏布局、键盘操作和系统「减少动态效果」设置。

**技术栈：** 原生 HTML / CSS / JavaScript · Node.js · SQLite。前后端同源，无第三方运行依赖，无前端构建步骤。

## 快速开始

需要 **Node.js 22.13 或更高版本**，推荐 Node.js 24（见 `.nvmrc`）。下载或克隆仓库后，在项目根目录执行：

```bash
npm start
```

浏览器打开 `http://127.0.0.1:3000`。无需单独安装数据库，也无需执行 `npm install`。请通过服务地址访问，不要双击 HTML 文件。

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `Zheguang@2026` |
| 普通成员 | `lin` | `Member@2026` |

首次开发启动自动创建 4 位演示用户、4 个项目、14 项任务和公告。数据保存在 `data/zheguang.sqlite`，重启不会覆盖已有内容。以上账号仅用于本地演示；正式部署使用独立数据库和自行设置的管理员凭据。

自定义端口等配置时，将 `.env.example` 复制为 `.env` 后修改。开发时运行 `npm run dev`，源码变化后服务会自动重启。

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 工作台 | 项目进度、我的待办、协作人数、最近动态与公告 |
| 项目空间 | 创建、编辑、归档、恢复、删除项目，添加或移除已有成员 |
| 任务看板 | 三列拖拽、负责人、优先级、截止日期、任务讨论与状态更新 |
| 我的任务 | 查看和筛选分配给自己的任务，完成或重新打开任务 |
| 搜索 | 使用 `Ctrl/Cmd + K` 搜索有权限访问的项目与任务 |
| 账号 | 注册、登录、保持会话、个人资料、修改密码与一次性恢复码 |
| 管理后台 | 成员、角色、账号启停、密码重置、公告、站点设置与最近 100 条操作记录 |

普通成员只能访问自己加入的项目；项目负责人管理项目及成员；管理员可管理全站。权限在后端校验。归档项目保留查看能力，恢复后才能继续编辑任务。移除成员后，其项目任务自动变为未分配。

手机和键盘用户可以在任务详情中直接切换状态，无需拖拽。

## 密码恢复

注册成功时显示一次恢复码，也可以在「账户设置」验证当前密码后重新生成。忘记密码时使用邮箱、恢复码和新密码重置，成功后原会话失效并生成新的恢复码。没有恢复码时由管理员重置密码。当前未接入邮件或短信服务。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `npm start` | 启动前端和后端 |
| `npm run dev` | 监听源码变化并重启 |
| `npm run check` | JavaScript 语法检查 |
| `npm test` | 运行自动化测试 |
| `npm run verify` | 顺序执行语法检查与全部测试 |

测试使用内存或临时数据库，不修改工作台数据，也不需要监听端口。覆盖会话、权限隔离、任务与讨论、公告、账号管理、恢复码并发、请求校验、静态资源、数据持久化、正式环境初始化，以及前端模板和异步切页。

GitHub Actions 已配置 Node.js 22 / 24 与 Linux / Windows 检查。自动化测试不替代浏览器验收；桌面、手机、拖拽及视觉效果仍需按 [验收清单](docs/验收清单.md) 实际检查。
