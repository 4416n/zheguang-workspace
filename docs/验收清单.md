# 浏览器验收清单

本清单记录待在实际浏览器中验证的视觉和交互项，不表示这些手动检查已经完成。先运行 `npm start`。

1. 用管理员账号登录，确认首页统计与项目卡片显示，刷新后保持会话。
2. 观察登录页光带、首页叠层、卡片悬浮与弹窗进入；在系统开启减少动态效果后，确认动画停止。
3. 创建项目，添加成员 `lin`，创建带描述和截止日期的任务并分配给他。
4. 把任务从「待开始」拖到「进行中」，刷新确认状态保存、描述和日期不丢失。
5. 打开任务，修改标题／优先级，添加评论；确认取消、Escape、点击遮罩和键盘 Tab 的行为。
6. 用成员账号登录，确认可以查看加入的项目，不能访问管理后台或无关项目。
7. 从项目移除成员，确认该成员失去访问权限，原负责人字段变为未分配。
8. 归档项目，确认任务不能继续编辑；恢复后能编辑；删除前显示明确确认信息。
9. 在后台创建和停用测试成员，修改公告和系统名称；确认界面更新与登录限制生效。
10. 在账户设置修改资料，生成恢复码。退出后使用恢复码重置密码，并保存新的恢复码。
11. 用 `Ctrl/Cmd + K` 搜索项目和任务；快速切换页面，确认不会显示上一页的数据。
12. 分别在 1440、1024、768、390、320 像素宽度检查布局：无整页横向溢出，侧栏可开合，表格可内部滚动，弹窗内容可滚动。
13. 手机端通过任务详情修改状态，确认所有主要功能无需拖拽也可操作。
